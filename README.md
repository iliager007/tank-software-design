# tank-software-design

При запуске на свободных клетках случайно появляются до трёх AI-танков.
Без аргументов сохраняются исходные позиции игрока и дерева.
Игрок управляется стрелками или WASD; AI перед каждой попыткой движения выбирает
случайное направление. Танк игрока — синий, танки AI отображаются темнее.

Случайное наполнение уровня 10×8 (по умолчанию 20 деревьев):

```bash
bash gradlew run --args='random'
bash gradlew run --args='random 30'
bash gradlew run --args='random 20 5'
```

Загрузка уровня из текстового файла (путь относительно рабочей директории):

```bash
bash gradlew run --args='file src/main/resources/level.txt'
bash gradlew run --args='file src/main/resources/level.txt 5'
```

Параметры: `random [obstacleCount [aiTankCount]]` или `file <path> [aiTankCount]`.
Количество AI-танков должно быть неотрицательным; `0` оставляет только игрока.
Если свободных клеток меньше запрошенного количества, создаётся столько танков,
сколько помещается. Танки генерируются один раз при загрузке уровня.

Формат файла UTF-8: `T` — дерево, `X` — старт игрока, `_` — пустая клетка.
Все строки должны иметь одинаковую ненулевую длину, `X` должен встречаться
ровно один раз. Первая строка — верхний ряд карты, координата `(0, 0)` —
нижняя левая клетка. Пример:

```text
___T__T___
__TT__TTTT
_________T
TTTT__T__T
_____X____
__________
__________
_________T
```

Размер уровня определяется содержимым файла; фон повторяет тайлы из `level.tmx`.
Размер окна остаётся 1280×1024; большие карты не масштабируются автоматически.
Деревья, другие танки и границы карты блокируют движение. Пока танк переезжает
между соседними клетками, обе клетки заняты им; исходная освобождается после
завершения движения. При одновременных попытках занять одну клетку первым
обрабатывается игрок, затем AI-танки в порядке создания. Генератор обеспечивает
уникальность занятых клеток, но не гарантирует связность свободной области.

Для подключения другого способа наполнения реализуйте `LevelSource` и передайте
его в конструктор `GameDesktopLauncher`. Источник возвращает `LevelDefinition`
с размерами карты и `WorldSettings`; игровая модель не зависит от загрузки файла,
генерации и графики.

`RandomTankLevelSource` добавляет случайные позиции AI к любому `LevelSource`.
`TankController` — стратегия выбора команды: `PlayerTankController` читает ввод,
`RandomTankController` выбирает направление через переданный `Random`.
`MoveTankCommand` реализует команду движения, а `GameWorld` исполняет её через
`CollisionMovementPolicy`, одинаковую для игрока и AI.

Неграфические тесты запускаются командой `bash gradlew test` (Gradle 6.1.1
требует совместимую JDK, например JDK 13). Тесты проверяют генерацию, команды,
стратегии, ввод, движение, границы, резервирование клеток и случайные симуляции
без графического контекста.
